# MiniKillingBlow

Simple addon that plays a sound when getting a player killing blow (NPCs don't trigger it).

Currently has 3 sound packs to choose from, as well as the ability to add your own sounds.

Sound packs:

- Unreal tournament
- Halo
- Guns
- One Gun

This is a brand new addon and features will be added over time.

Feedback and feature requests are more than welcome!
